# Fundación Vicentina

Sitio web institucional desarrollado para la **Fundación Vicentina**, una organización social sin fines de lucro de Córdoba, Argentina.

El proyecto fue diseñado para presentar la identidad, misión, proyectos, actividades y noticias de la organización, además de facilitar diferentes formas de participación, colaboración y contacto.

## Overview

**Fundación Vicentina** es un sitio web institucional multipágina enfocado en comunicar las actividades y proyectos de la organización y brindar a los visitantes diferentes medios para conocerla y colaborar.

El sitio cuenta con una navegación estructurada por diferentes áreas institucionales, incluyendo información sobre la fundación, proyectos sociales, transparencia, empresas, noticias, colaboración, donaciones y contacto.

El proyecto combina **HTML, CSS, JavaScript y PHP**, utilizando una estructura organizada de páginas y recursos para construir una experiencia web responsive.

## Responsive Design

The website was developed with responsive design principles to provide an appropriate experience across different screen sizes.

The navigation includes separate desktop and mobile implementations, with a mobile menu designed specifically for smaller screens.

CSS media queries and flexible layouts are used to adapt the content and interface to different viewport dimensions.

## JavaScript

JavaScript is used to provide interactive behavior throughout the website, including:

* Mobile navigation.
* Dropdown menus.
* Smooth scrolling.
* Search functionality.
* Image sliders.
* Animated counters.
* Back-to-top navigation.
* Dynamic interface interactions.

## PHP

The project includes PHP scripts for server-side functionality.

The contact section uses a PHP script to receive information submitted through the website's contact form and process the request.

Because PHP requires server-side execution, this functionality requires a hosting environment with PHP support.

## Design Approach

The website was designed around the visual identity of the foundation, with an emphasis on:

* Clear information hierarchy.
* Accessible navigation.
* Responsive layouts.
* Visual representation of social projects.
* Prominent calls to action.
* Consistent typography.
* Image-based content presentation.
* Separation of institutional and project-related information.

The interface uses **Poppins** as its primary web font and Font Awesome for interface icons.
